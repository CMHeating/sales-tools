Install Availability Admin Training

This page explains how to access and use the Install Availability Board during rollout.

Your PIN

Your admin PIN is the last 4 digits of your work phone number.

If you do not have a work phone, use the last 4 digits of your personal phone number.

Example: (425) 555-1234 → PIN 1234

Basic Use

  • Open the Install Board.
  • Tap ADMIN / HCA EDIT.
  • Enter your PIN.
  • Select a slot to mark availability, sold work, or project details.
  • Admins can move jobs between crews and days.
  • Use Morning Install Booked when afternoon is still available.
  • Use Afternoon Install Booked when morning is still available.

Important

  • Do not share your PIN.
  • Do not leave edit windows open.
  • If you are unsure, ask Amy or Geoff before changing a slot.
