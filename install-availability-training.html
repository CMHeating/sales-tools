Realtime Architectural Rules

The system handles transactions concurrently to guarantee that schedule lines never experience race condition overwrites:

1. Realtime Row Synchronization

The layout utilizes persistent active websocket event listeners. When an Admin shifts a resource slot or an HCA saves a new installation, the changes update instantly across every computer monitor currently viewing the board without refreshing.

2. Concurrent Lock Mitigation

The absolute fraction an HCA clicks into an individual calendar cell, the system registers a lock token in the cloud. If a second user clicks the same slot, they are greeted with an active alert stating the block is currently occupied. Locks automatically dissolve if the form is abandoned or closed.

HCA Training Scenarios (Practice Matrix)

Open the test board file using the button in the sidebar and run through these modules step-by-step to build operational muscle-memory:

Scenario A — Admin
Initializing the Week's Board Geometry
  • Log into the test scheduler using an authorized Admin PIN.
  • Click the "⚡ Mass Populate Open" button in the top navigation panel.
  • The engine populates the current active matrix lines with default OPEN states, bypassing holiday or custom off-duty tracks.
Scenario B — Admin
Handling an Emergency Logistics Realignment (Swap)
  • Click the orange "🔄 Swap Crews" tool action.
  • Select the primary constrained crew line as the source vector and a flexible crew as the target vector.
  • Confirm execution. The engine completely mirrors both profiles instantly while logging the data swap footprint to the audit trail.
Scenario C — Admin
Locking a Row for Special Projects (Hold)
  • Click an open cell on any preferred line ➔ Choose the status status HOLD.
  • Click Save. The cell locks into an orange Admin blockout state. HCAs cannot click or manipulate this block.
Scenario D — HCA
Attempting an Unauthorized Admin Interaction
  • Log out of Admin status, and authenticate using an authorized HCA PIN.
  • Click on a row designated with an active orange HOLD badge.
  • The system blocks your execution context, showing a notice requiring supervisor approval.
Scenario E — HCA
Marking a Newly Closed Deal as Sold
  • Scan the workspace columns for a clean green OPEN cell matching your timeframe.
  • Click the open space ➔ Shift the dropdown assignment to FULL DAY INSTALL — FILLED.
  • Enter your mandatory tracking Job Number and any custom notes relative to equipment lines. Click Save.
Scenario F — Admin
Verifying Row Footprints and Changesets via Audits
  • Click the "📋 Audit Logs" engine parameter inside the top navigation bar.
  • Review the transactional audit grid to track operator identity tags, timestamps, old/new states, and specific job reference markers.
