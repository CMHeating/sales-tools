Step-by-Step Process

Follow these steps in order. Escalate to Geoff or Amy before proceeding if anything does not match.

1. DL Capture — Source of Truth

  • Capture DL for all homeowner(s) required to sign.
  • DL is the source of truth for legal-name spelling.
  • If multiple homeowners are required to sign, each signer must be verified.

2. Mortgage Statement / Deed

  • Collect the most recent mortgage statement if there is an active mortgage.
  • If the home is paid off, collect the deed. Assessor records can be behind.
  • If the mortgage statement shows two homeowners, verify both names against DL capture.
  • Confirm spelling exactly before contract generation.

3. Credit Authorization + Equifax

  • Have homeowner(s) complete the ServiceTitan credit authorization form.
  • Then use Equifax InterConnect for the credit pull.
  • Target credit score remains 640+ unless updated by leadership.
Open Equifax Credit Pull

4. Trust Handling

  • If the home is held in a trust, list the trust first.
  • List the executor/trustee as the secondary name.
  • This is rare. Escalate to Geoff or Amy if signer setup is unclear.

5. County Assessor Verification

  • Verify current named owners on the applicable county assessor site.
  • Confirm property address matches the job address.
  • Confirm named owners match mortgage/deed documents and DL spelling.
  • Assessor verification does not replace the deed if the home is paid off.

6. ServiceTitan Estimate Rule

  • Add the Comfort Club rental estimate in ServiceTitan.
  • The rental package must be within the first five estimates.
  • A la carte estimates in the first five positions can create contract generation/import issues.
  • Escalate before proceeding if the estimate structure looks wrong.

7. Current Second-Look / Payment Review Threshold

  • Call (770) 817-3737 or email credit@reliableair.com if credit is near 640.
  • Call or email if payment is above the current internal review threshold.
  • Current payment review threshold: $239.99/month until updated.
  • Mon–Fri finance approvals: 8:00 AM – 4:00 PM EDT.
  • Saturday finance approvals: 9:00 AM – 3:00 PM EDT.
  • Sunday finance approvals: closed.
  • Email if any credit result is unclear.

8. Contract Signing

  • Generate the rental contract from ServiceTitan.
  • Verify all required homeowner names.
  • Verify property address, rental package, monthly payment, term, and residual language.
  • Confirm COD extras are separated correctly.
  • All required homeowners must sign.

9. Penny Test Form

  • Complete the penny test form in ServiceTitan.
  • This verifies the card used for monthly rental payments.
  • Do not mark the Comfort Club rental setup complete until the penny test passes.

10. Final Confirmation

  • DL captured for all required signers.
  • Mortgage statement or deed collected.
  • Credit authorization completed.
  • Equifax credit pull completed.
  • Trust signer setup verified if applicable.
  • County assessor ownership verified.
  • ServiceTitan estimate is within the first five estimates.
  • Second-look review sent if needed.
  • Contract signed by all required homeowners.
  • Penny test form completed and passed.
  • ServiceTitan notes updated.

Escalate to Geoff or Amy

  • Owner name does not match DL / mortgage / deed / assessor.
  • One listed owner is missing.
  • Property is in a trust and signer setup is unclear.
  • Credit is near 640 or payment is above the current internal threshold.
  • Contract does not generate correctly.
  • A la carte estimates interfere with the first five estimate slots.
  • Penny test fails.
  • HCA is unsure whether the Comfort Club rental file is complete.
